# Garment Pricing App

Single-file web app backed by Supabase.

## Setup
1. Copy `config.example.js` to `config.js`.
2. Fill in your Supabase email/password, or leave blank to use anonymous sign-in
   (requires "Allow anonymous sign-ins" in Supabase → Authentication → Providers).
3. Open `index_html.html` in your browser.

`config.js` is git-ignored. Keep this repo private.
